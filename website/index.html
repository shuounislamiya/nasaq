كل ما تحتاجه في لوحة واحدة

أدوات احترافية لمصممي الويب وعشّاق التخصيص والقرّاء الذين يريدون مظهرًا أفضل لأي موقع.

ثلاثة خطوط عربية احترافية

Tajawal، IBM Plex Sans Arabic، وAmiri مدمجة في الإضافة. تعمل بدون إنترنت ودون أي تتبع.

اتجاه الصفحة بكبسة زر

قسم بارز لتبديل اتجاه أي موقع: RTL، LTR، أو تلقائي حسب لغة المحتوى. مثالي للمحتوى العربي.

اختيار العنصر بالماوس

انقر على أي عنصر في الصفحة لاختياره. خوارزمية ذكية تولّد CSS selector مستقر يقاوم تغيّرات الموقع.

محرّر CSS كامل

اكتب CSS مخصّص بحرية كاملة. التطبيق فوري على الصفحة دون الحاجة لإعادة تحميل.

حفظ تلقائي بلا أزرار

كل تعديل يُحفظ فورًا. لا تحتاج لزر "حفظ". يظل النمط مُطبَّقًا حتى بعد إعادة فتح المتصفح.

خصوصية مطلقة

كل البيانات محفوظة محليًا. لا اتصال خارجي، لا تتبّع، لا إعلانات. الكود مفتوح للمراجعة.

لوحة جانبية تبقى مفتوحة

على عكس النوافذ المنبثقة، لوحة نَسَق تظل مفتوحة أثناء تصفّحك بين التبويبات. مرنة وعملية.

تصدير واستيراد

احفظ كل إعداداتك كملف JSON. انقلها بين أجهزتك أو شاركها مع أصدقائك بسهولة.

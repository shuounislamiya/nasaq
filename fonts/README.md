# مجلد الخطوط — Nasaq

هذا المجلد يحتوي ملفات الخطوط المدمجة (woff2) التي تُحمَّل **محليًا** من الإضافة دون أي اتصال خارجي.

## التحميل التلقائي

من جذر المشروع، شغّل:

```bash
python download-fonts.py
```

سيُحمَّل كل الخطوط من Google Fonts ويضعها هنا بالتسمية الصحيحة.

## التسمية

كل ملف يأخذ الصيغة: `{font-id}-{weight}.woff2`

الـ `font-id` يجب أن يطابق `BUNDLED_FONTS` في `content/inject.js`.

## الحجم المتوقع

بعد تحميل كل الخطوط، يكون مجموع الحجم حوالي **1.5–2 MB** (مقبول جدًا لإضافة كروم).

## التحقق من التحميل

في `content/inject.js`، الإضافة تولّد `@font-face` ديناميكيًا لكل ملف موجود في هذا المجلد. أي ملف ناقص سيؤدي إلى failover صامت إلى خط النظام، لذا تأكد من تحميل كل الملفات قبل النشر.
